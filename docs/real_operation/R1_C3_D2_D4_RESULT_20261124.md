## 4. ModemManager、udev与时间证据

现有/etc/udev/rules.d/99-ttyACM0.rules的忽略行带多余字符：
ENV{ID_MM_PORT_IGNORE}="1"1"。现场设备有ID_MM_CANDIDATE=1，忽略标记未生效。
原别名规则匹配所有ttyACM设备，未来出现第二个ACM设备可能误指向rrc。
本轮只临时隔离ModemManager，没有修改该文件、全局触发udev或宣称其为根因。
建议后续备份并审核按VID/PID/序列号精确匹配的忽略/别名规则，再评审恢复ModemManager；
不能只修字符串后就假定探测已停止，须观察实际设备属性及打开者。

另发现SSH现有LD_PRELOAD指向Open3D共享库。相同date -u在继承环境下显示
本地时刻并带Z，去掉该单个预加载变量后显示正确UTC；Python明确时区及epoch数值正常。
因此证据目录名r1_c3_d2d4_20261124T125001Z的后缀不是可信UTC，保留原名以便追溯。
时序使用原始system/monotonic ns、Python时区和journal +0800，不改写采样时间。
维护服务环境核验没有LD_PRELOAD；全局配置未修改。
主机绝对时钟未做外部精度标定，不据此通过相机/关节采样同步验收。
这项时间格式异常不等于已确认的USB或SSD故障原因。
